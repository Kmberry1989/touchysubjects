# Touchy Subjects Pets SCAD Collection v2

This archive includes:
- Base mini collection (TS-PET-001 through TS-PET-008)
- Premium / utility / enrichment expansion (A, B, C)
- Modular enrichment system add-ons for path #4 (C06 through C13)

Recommended prototype order:
1. Wall hooks, trays, anchors, mounts
2. Tag silencers / holders in TPU
3. Track system connectors and stations

Default slicer starting point:
- Layer height: 0.20 mm
- Walls: 3-4
- Infill: 15-25% gyroid
- PETG for utility parts
- TPU for soft contact parts

Note: Inspect all pet-contact prints regularly and discard any cracked or damaged parts.
